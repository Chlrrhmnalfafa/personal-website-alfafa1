# Personal Website — Muhammad Cholilurrahman Alfafa

Website personal untuk tugas Informatika/TIK kelas XII.

## File
- `index.html` — struktur halaman
- `style.css` — desain dan responsive layout
- `script.js` — menu mobile, animasi reveal, dan tahun otomatis
- `assets/foto.jpg` — foto profil

## Upload ke GitHub
1. Buat repository baru, misalnya `personal-website-alfafa`.
2. Upload semua file dan folder `assets`.
3. Pastikan `index.html` berada di folder utama repository.
4. Jadikan repository Public jika diminta guru.

## Deploy ke Vercel
1. Login ke Vercel menggunakan GitHub.
2. Pilih **Add New Project**.
3. Import repository website.
4. Klik **Deploy**.
5. Setelah selesai, salin URL website untuk dikumpulkan.
